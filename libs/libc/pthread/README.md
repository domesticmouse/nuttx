# POSIX Threads User-Space Library (`libs/libc/pthread`)

## Overview
Implements the user-space C library portion of POSIX Threads (`<pthread.h>`) and C11 `<threads.h>` (`thrd_exit`) when `CONFIG_DISABLE_PTHREAD` is not set. Covers thread creation and termination (`pthread_create`, `pthread_exit`, `pthread_self`, `pthread_equal`, `pthread_yield`), thread attributes (`pthread_attr_*`), cancellation (`pthread_setcancelstate`, `pthread_setcanceltype`, `pthread_testcancel`), cleanup handlers (`pthread_cleanup_push`, `pthread_cleanup_pop`), thread-specific data (TLS keys `pthread_key_create`, `pthread_setspecific`, `pthread_getspecific`, `pthread_key_delete`), mutexes and robust mutexes (`pthread_mutex_*`, `pthread_mutexattr_*`), condition variables (`pthread_cond_*`, `pthread_condattr_*`), barriers (`pthread_barrier_*`, `pthread_barrierattr_*`), read-write locks (`pthread_rwlock_*`, `pthread_rwlockattr_*`), spinlocks (`pthread_spin_*`), and one-time initialization (`pthread_once`).

## Invariants
- Pthread functions return positive `errno` error codes directly as their return value and do NOT modify the thread's `errno` variable (`[pthread_create.c:pthread_create]`, `[pthread_mutex.c:pthread_mutex_take]`).
- TLS keys passed to `[pthread_getspecific.c:pthread_getspecific]`, `[pthread_setspecific.c:pthread_setspecific]`, and `[pthread_keydelete.c:pthread_key_delete]` must satisfy `0 <= key < CONFIG_TLS_NELEM`.
- Non-recursive mutexes held by the calling thread return `EDEADLK` on `[pthread_mutex.c:pthread_mutex_take]` and `EBUSY` on `[pthread_mutex.c:pthread_mutex_trytake]`; inconsistent robust mutexes (`_PTHREAD_MFLAGS_INCONSISTENT`) return `EOWNERDEAD`.

## Side Effects
- `[pthread_create.c:pthread_create]` spawns a new thread via the `nx_pthread_create` system call wrapped in `pthread_startup()`, which guarantees `[pthread_exit.c:pthread_exit]` is invoked when the entry routine returns.
- `[pthread_mutex.c:pthread_mutex_take]` and `[pthread_mutex.c:pthread_mutex_give]` link and unlink robust mutexes on the thread's TLS `tl_mhead` list (`tls_get_info()->tl_mhead`) and lock/unlock the underlying `mutex->mutex`.
- `[pthread_keycreate.c:pthread_key_create]` and `[pthread_keydelete.c:pthread_key_delete]` acquire the task-group lock (`info->ta_lock`) and mutate the task group's `ta_tlsdtor` destructor array and `ta_tlsset` bitmask.
- `[pthread_spinlock.c:pthread_spin_lock]` and `[pthread_spinlock.c:pthread_spin_unlock]` issue `BOARDIOC_SPINLOCK` `boardctl()` calls or atomic compare-and-swap loops with `sched_yield()`.
