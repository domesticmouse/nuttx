# Miscellaneous C Library Utilities and OS Primitives (`libs/libc/misc`)

## Overview
Provides a broad collection of C library utility routines, data structures, checksum/hash/cipher primitives, VFS `*at` wrappers, and user/kernel synchronization helpers (`nxmutex`, `nxrmutex`). Subsystems include circular buffers (`circbuf_*`), integer ID red-black trees (`idr_*`), bitmaps (`bitmap_*`, `find_next_bit`), stack backtrace pooling (`backtrace_*`), CRC-8/16/32/64 and TEA encryption, ISO-TP CAN framing, keyboard/SLCD stream codecs, `glob`/`fnmatch`, `mntent`, `fdsan`/`fdcheck` descriptor tagging, and 64-bit integer emulation helpers.

## Invariants
- Recursive mutex lock count `rmutex->count` must be `> 0` before calling `[lib_mutex.c:nxrmutex_unlock]` and `< UINT_MAX` when locking (`[lib_mutex.c:nxrmutex_lock]`).
- `circ` passed to `[lib_circbuf.c:circbuf_init]` must be non-NULL, and if `base` is non-NULL, `bytes` must be non-zero (`DEBUGASSERT(!base || bytes)`).
- File descriptors closed via `[lib_fdsan.c:android_fdsan_close_with_tag]` must match the expected `tag` stored in the process fdtable or trigger a fatal `ferr` / `PANIC`.

## Side Effects
- `[lib_mutex.c:nxmutex_clocklock]` and `[lib_mutex.c:nxrmutex_lock]` block the calling task on `mutex->sem` via `nxsem_wait()` / `nxsem_clockwait()` and record holder backtraces when `CONFIG_LIBC_MUTEX_BACKTRACE` is enabled.
- `[lib_circbuf.c:circbuf_init]`, `[lib_idr.c:idr_alloc]`, `[lib_glob.c:glob]`, and `[lib_tempbuffer.c:lib_get_tempbuffer]` allocate and free memory or atomic pool slots (`g_tempbuffer.free_bitmap`).
- `*at` wrappers (`[lib_openat.c:openat]`, `[lib_fstatat.c:fstatat]`, `[lib_mkdirat.c:mkdirat]`, `[lib_utimensat.c:utimensat]`) resolve relative paths via `fcntl(dirfd, F_GETPATH, ...)` (`[lib_getfullpath.c:lib_getfullpath]`) and invoke underlying VFS system calls.
