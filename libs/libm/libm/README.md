# libm

## Overview
Implements the native NuttX standard C mathematical library (`libm`), providing single-precision (`float`), double-precision (`double`, guarded by `CONFIG_HAVE_DOUBLE`), and extended-precision (`long double`, guarded by `CONFIG_HAVE_LONG_DOUBLE`) trigonometric, hyperbolic, exponential, logarithmic, power, Bessel, gamma/error, rounding, remainder, and floating-point manipulation functions, along with architecture-specific FPU overrides.

## Invariants
- Kernel polynomial helpers `__cos.c:__cos` and `__sin.c:__sin` require input `x` to be reduced to `[-pi/4, pi/4]` in magnitude.
- Double-precision implementations are compiled only when `CONFIG_HAVE_DOUBLE` is enabled, and software implementations of functions with architectural overrides (such as `lib_sqrtf.c:CONFIG_LIBM_ARCH_SQRTF`) are excluded when the corresponding arch Kconfig flag is set.

## Side Effects
- Domain errors on functions such as `lib_sqrt.c:sqrt` and `lib_sqrtf.c:sqrtf` (`x < 0`) set thread `errno` to `EDOM` via `set_errno(EDOM)`.
- `lib_lgamma.c:lgamma` mutates the static sign variable `lib_lgamma.c:g_signgam` (whereas `lib_lgamma.c:lgamma_r` writes to caller-provided `*signgamp`).
