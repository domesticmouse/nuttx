# `xtensa` Architecture Boards (`boards/xtensa`)

## Overview
Intermediate blueprint grouping board support packages (BSPs) and SoC/MCU families for the `xtensa` architecture (3 chip/family subdirectories).

## Subdirectories & Boundaries
- [`esp32`](./esp32/README.md) - Intermediate blueprint grouping board support packages and shared board drivers for the `esp32` SoC/MCU family under the `xtensa` architecture (15 subdirectories).
- [`esp32s2`](./esp32s2/README.md) - Intermediate blueprint grouping board support packages and shared board drivers for the `esp32s2` SoC/MCU family under the `xtensa` architecture (4 subdirectories).
- [`esp32s3`](./esp32s3/README.md) - Intermediate blueprint grouping board support packages and shared board drivers for the `esp32s3` SoC/MCU family under the `xtensa` architecture (14 subdirectories).
