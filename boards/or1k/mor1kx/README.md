# `mor1kx` Family Boards (`boards/or1k/mor1kx`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `mor1kx` SoC/MCU family under the `or1k` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`or1k`](./or1k/README.md) - Board Support Package (BSP) blueprint for `or1k` (`or1k` / `mor1kx`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`.
