# `bm3803` Family Boards (`boards/sparc/bm3803`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `bm3803` SoC/MCU family under the `sparc` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`xx3803`](./xx3803/README.md) - Board Support Package (BSP) blueprint for `xx3803` (`sparc` / `bm3803`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`.
