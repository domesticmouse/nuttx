# `a527` Family Boards (`boards/arm64/a527`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `a527` SoC/MCU family under the `arm64` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`avaota-a1`](./avaota-a1/README.md) - Board Support Package (BSP) blueprint for `avaota-a1` (`arm64` / `a527`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`.
