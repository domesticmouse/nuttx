# `rk3588` Family Boards (`boards/arm64/rk3588`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `rk3588` SoC/MCU family under the `arm64` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`orangepi-5-pro`](./orangepi-5-pro/README.md) - Board Support Package (BSP) blueprint for `orangepi-5-pro` (`arm64` / `rk3588`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`, `ostest`.
