# `imx8` Family Boards (`boards/arm64/imx8`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `imx8` SoC/MCU family under the `arm64` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`imx8qm-mek`](./imx8qm-mek/README.md) - Board Support Package (BSP) blueprint for `imx8qm-mek` (`arm64` / `imx8`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`.
