# `z180` Family Boards (`boards/z80/z180`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `z180` SoC/MCU family under the `z80` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`p112`](./p112/README.md) - Board Support Package (BSP) blueprint for `p112` (`z80` / `z180`). Coordinates board initialization, headers, and tooling across `include`. Includes build configurations: `ostest`.
