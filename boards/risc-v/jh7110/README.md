# `jh7110` Family Boards (`boards/risc-v/jh7110`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `jh7110` SoC/MCU family under the `risc-v` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`star64`](./star64/README.md) - Board Support Package (BSP) blueprint for `star64` (`risc-v` / `jh7110`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`.
