# `jz4780` Family Boards (`boards/mips/jz4780`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `jz4780` SoC/MCU family under the `mips` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`ci20`](./ci20/README.md) - Board Support Package (BSP) blueprint for `ci20` (`mips` / `jz4780`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `jumbo`, `net`, `nsh`.
