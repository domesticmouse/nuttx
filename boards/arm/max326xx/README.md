# `max326xx` Family Boards (`boards/arm/max326xx`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `max326xx` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
