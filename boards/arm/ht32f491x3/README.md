# `ht32f491x3` Family Boards (`boards/arm/ht32f491x3`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `ht32f491x3` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`esk32`](./esk32/README.md) - Board Support Package (BSP) blueprint for `esk32` (`arm` / `ht32f491x3`). Coordinates board initialization, headers, and tooling across `include, src, tools`. Includes build configurations: `nsh`, `pwm`.
