# `nuc1xx` Family Boards (`boards/arm/nuc1xx`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `nuc1xx` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`nutiny-nuc120`](./nutiny-nuc120/README.md) - Board Support Package (BSP) blueprint for `nutiny-nuc120` (`arm` / `nuc1xx`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`.
