# `n32h7` Family Boards (`boards/arm/n32h7`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `n32h7` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
