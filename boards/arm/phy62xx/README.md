# `phy62xx` Family Boards (`boards/arm/phy62xx`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `phy62xx` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`phy6222`](./phy6222/README.md) - Board Support Package (BSP) blueprint for `phy6222` (`arm` / `phy62xx`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`, `phy_sbp`.
