# `eoss3` Family Boards (`boards/arm/eoss3`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `eoss3` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`quickfeather`](./quickfeather/README.md) - Board Support Package (BSP) blueprint for `quickfeather` (`arm` / `eoss3`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`.
