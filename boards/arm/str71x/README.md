# `str71x` Family Boards (`boards/arm/str71x`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `str71x` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`olimex-strp711`](./olimex-strp711/README.md) - Board Support Package (BSP) blueprint for `olimex-strp711` (`arm` / `str71x`). Coordinates board initialization, headers, and tooling across `include, scripts, src`. Includes build configurations: `nettest`, `nsh`.
