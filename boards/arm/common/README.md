# `common` Family Boards (`boards/arm/common`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `common` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`stm32`](./stm32/README.md) - Board Support Package (BSP) blueprint for `stm32` (`arm` / `common`). Coordinates board initialization, headers, and tooling across `include, src`.
