# `stm32wl5` Family Boards (`boards/arm/stm32wl5`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `stm32wl5` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
