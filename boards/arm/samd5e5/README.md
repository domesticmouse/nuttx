# `samd5e5` Family Boards (`boards/arm/samd5e5`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `samd5e5` SoC/MCU family under the `arm` architecture (2 subdirectories).

## Subdirectories & Boundaries
- [`metro-m4`](./metro-m4/README.md) - Board Support Package (BSP) blueprint for `metro-m4` (`arm` / `samd5e5`). Coordinates board initialization, headers, and tooling across `include, scripts, src`. Includes build configurations: `nsh`.
- [`same54-xplained-pro`](./same54-xplained-pro/README.md) - Board Support Package (BSP) blueprint for `same54-xplained-pro` (`arm` / `samd5e5`). Coordinates board initialization, headers, and tooling across `include, scripts, src`. Includes build configurations: `nsh`.
