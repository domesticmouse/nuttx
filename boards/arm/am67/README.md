# `am67` Family Boards (`boards/arm/am67`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `am67` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`t3-gem-o1`](./t3-gem-o1/README.md) - Board Support Package (BSP) blueprint for `t3-gem-o1` (`arm` / `am67`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `netnsh`, `nsh`.
