# `moxart` Family Boards (`boards/arm/moxart`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `moxart` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`moxa`](./moxa/README.md) - Board Support Package (BSP) blueprint for `moxa` (`arm` / `moxart`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`.
