# `c5471` Family Boards (`boards/arm/c5471`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `c5471` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`c5471evm`](./c5471evm/README.md) - Board Support Package (BSP) blueprint for `c5471evm` (`arm` / `c5471`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `httpd`, `nettest`, `nsh`.
