# `a1x` Family Boards (`boards/arm/a1x`)

## Overview
Intermediate blueprint grouping board support packages and shared board drivers for the `a1x` SoC/MCU family under the `arm` architecture (1 subdirectories).

## Subdirectories & Boundaries
- [`pcduino-a10`](./pcduino-a10/README.md) - Board Support Package (BSP) blueprint for `pcduino-a10` (`arm` / `a1x`). Coordinates board initialization, headers, and tooling across `include, src`. Includes build configurations: `nsh`.
