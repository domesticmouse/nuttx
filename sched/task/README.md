# Task Lifecycle Management (`sched/task`)

## Overview
The `sched/task` component manages the complete lifecycle of NuttX user tasks and kernel threads. It provides TCB and stack initialization (`nxtask_init`, `nxtask_uninit`, `nxtask_setup_scheduler`, `nxtask_setup_stackargs`, `nxtask_setup_name`), PID hash assignment (`nxtask_assign_pid`), task and kernel thread creation (`task_create`, `task_create_with_stack`, `nxtask_create`, `nxthread_create`, `kthread_create`, `kthread_create_with_stack`), scheduler activation (`nxtask_activate`, `nxtask_start`), POSIX and in-memory spawning (`posix_spawn`, `task_spawn`, `spawn_execattrs`, `spawn_file_actions`), `fork()` and `vfork()` child setup and rendezvous (`nxtask_setup_fork`, `nxtask_start_fork`, `nxtask_resume_vfork`, `nxtask_abort_fork`), `execve()` binary replacement, cancellation point notifications (`nxnotify_cancellation`), task deletion/termination/exit (`task_delete`, `nxtask_delete`, `nxtask_terminate`, `_exit`, `nxtask_exit`, `nxtask_exithook`, `nxtask_recover`), task restart (`task_restart`), reparenting (`task_reparent`), PID/TID/PPID queries (`nxsched_getpid`, `nxsched_gettid`, `nxsched_getppid`, `getppid`, `task_getgroup`), and `prctl` control operations.

## Interface
- `task_init.c:nxtask_init`, `task_init.c:nxtask_uninit`, `task.h:nxtask_setup_scheduler` (`task_setup.c:nxtask_setup_scheduler`), `task_setup.c:pthread_setup_scheduler`, `task.h:nxtask_setup_stackargs` (`task_setup.c:nxtask_setup_stackargs`), `task.h:nxtask_setup_name` (`task_setup.c:nxtask_setup_name`), `task.h:nxtask_joininit` (`task_join.c:nxtask_joininit`), `task.h:nxtask_joindestroy` (`task_join.c:nxtask_joindestroy`) - Initializes a TCB, assigns a unique PID in `g_pidhash`, allocates or attaches user/kernel stacks, carves TLS and stack `argv[]` frames, binds a new task group, and places the TCB on `g_inactivetasks`.
- `task_create.c:nxthread_create`, `task_create.c:nxtask_create`, `task_create.c:task_create`, `task_create.c:task_create_with_stack`, `task_create.c:kthread_create`, `task_create.c:kthread_create_with_stack`, `task_activate.c:nxtask_activate`, `task.h:nxtask_start` (`task_start.c:nxtask_start`) - Allocates, initializes, activates, and starts user tasks (`TCB_FLAG_TTYPE_TASK`) and kernel threads (`TCB_FLAG_TTYPE_KERNEL`).
- `task_posixspawn.c:posix_spawn`, `task_spawn.c:task_spawn`, `spawn.h:spawn_execattrs` (`task_spawnparms.c:spawn_execattrs`), `task_spawnparms.c:spawn_file_actions`, `task_spawnparms.c:spawn_file_is_duplicateable`, `task_execve.c:execve` - Spawns new child tasks from filesystem binaries (`exec_spawn`) or memory entry points with POSIX spawn file actions (`close`, `dup2`, `open`) and scheduling/signal attributes, or replaces the current task via `exec()` followed by `_exit(0)`.
- `task_fork.c:nxtask_setup_fork`, `task_fork.c:nxtask_start_fork`, `task_fork.c:nxtask_resume_vfork`, `task_fork.c:nxtask_abort_fork` - Implements architecture-independent `fork()` and `vfork()` setup, address environment duplication or sharing, stack/TLS inheritance, parent suspension on `child->vfork_rel`, and error rollback.
- `exit.c:_exit`, `task.h:nxtask_exit` (`task_exit.c:nxtask_exit`), `task.h:nxtask_exithook` (`task_exithook.c:nxtask_exithook`), `task.h:nxtask_terminate` (`task_terminate.c:nxtask_terminate`), `task_delete.c:nxtask_delete`, `task_delete.c:task_delete`, `task.h:nxtask_recover` (`task_recover.c:nxtask_recover`), `task.h:nxnotify_cancellation` (`task_cancelpt.c:nxnotify_cancellation`), `task_restart.c:task_restart` - Handles voluntary exit, synchronous/deferred cancellation (`ECANCELED`), forceful termination, resource recovery (mutexes, semaphores, mqueues, watchdogs, sporadic timers), `SIGCHLD` parent notification, and task reset/restart.
- `task_getpid.c:nxsched_getpid`, `task_gettid.c:nxsched_gettid`, `task_getppid.c:nxsched_getppid`, `task_getppid.c:getppid`, `task_getgroup.c:task_getgroup`, `task_reparent.c:task_reparent`, `task_argvstr.c:nxtask_argvstr`, `task_prctl.c:prctl` - Queries process/thread/parent IDs and task groups, reparents child groups, formats command-line arguments, and executes `prctl` commands (`PR_SET_NAME`, `PR_GET_NAME`, `PR_SET_NAME_EXT`, `PR_GET_NAME_EXT`, `PR_SET_DUMPABLE`, `PR_GET_DUMPABLE`, `PR_CAPS_DROP`, `PR_CAPS_GET`).

## Invariants
- `task_init.c:nxtask_init`, `task_delete.c:nxtask_delete`, `task_restart.c:nxtask_restart`, and `task_start.c:nxtask_start` reject or assert against `TCB_FLAG_TTYPE_PTHREAD` TCBs (which are managed by `sched/pthread`).
- Unprivileged tasks (`(rtcb->flags & TCB_FLAG_TTYPE_MASK) != TCB_FLAG_TTYPE_KERNEL`) cannot delete kernel threads in `task_delete.c:nxtask_delete` (returns `-EACCES`), and task creation requires `PR_CAP_SPAWN` capability (`task_create.c:nxtask_create`, `task_spawn.c:nxtask_spawn_create`).
- In `task_fork.c:nxtask_setup_fork`, a POSIX `fork()` child (`!vfork`) duplicates the parent's address environment (`addrenv_fork`), selects it immediately (`addrenv_select`) so TLS and stack writes land in the child's pages rather than corrupting the parent, and clears `TCB_FLAG_FREE_STACK` (`fork_inherit_stack`); `task_fork.c:nxtask_start_fork` or `task_fork.c:nxtask_abort_fork` must restore the parent's address environment (`fork_restore_parent_env`).
- In `task_fork.c:nxtask_start_fork`, a `vfork()` parent blocks uninterruptibly on its stack-allocated semaphore `rel` (`child->vfork_rel`) until `task_fork.c:nxtask_resume_vfork` clears `child->vfork_rel` and posts `rel` during child TCB teardown or `exec_swap()`.
- `task_exithook.c:nxtask_exithook` asserts `(tcb->flags & TCB_FLAG_EXIT_PROCESSING) != 0`, and `task_terminate.c:nxtask_terminate` sets `TCB_FLAG_EXIT_PROCESSING` inside a critical section to prevent double termination.

## Side Effects
- Allocates and frees TCBs, task groups, stacks, and dynamically expands `g_pidhash` (`kmm_zalloc`, `kmm_free`, `up_create_stack`, `up_release_stack`, `nxsched_release_tcb`).
- Mutates scheduler task queues (`g_inactivetasks`, ready-to-run queues, blocked queues), issues cross-CPU SMP IPIs (`nxsched_smp_call_single`) when terminating or restarting a task running on another CPU, and switches CPU context (`up_switch_context`, `up_exit`).
- Sends `SIGCHLD` to parent task groups, posts `group->tg_exitsem`, wakes blocked threads at cancellation points with `ECANCELED`, recovers stranded mutexes/semaphores/mqueues/watchdogs (`nxtask_recover`), and leaves/destroys task groups (`group_leave`).
