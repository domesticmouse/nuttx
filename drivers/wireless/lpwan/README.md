# Low-Power Wide-Area Network (LPWAN) Drivers (`drivers/wireless/lpwan`)

## Overview
Groups Low-Power Wide-Area Network (LPWAN) LoRa, FSK, and LoRaWAN concentrator transceiver drivers.

## Subdirectories & Boundaries
- `rn2xx3`: [./rn2xx3/README.md](./rn2xx3/README.md) - Microchip RN2483/RN2903 UART-controlled LoRa and FSK transceiver character driver.
- `sx126x`: [./sx126x/README.md](./sx126x/README.md) - Semtech SX1261/SX1262/SX1268 sub-GHz LoRa and GFSK SPI transceiver character driver.
- `sx127x`: [./sx127x/README.md](./sx127x/README.md) - Semtech SX1272/SX1276/SX1277/SX1278/SX1279 LoRa and FSK/OOK SPI transceiver character driver.
- `sx1301`: [./sx1301/README.md](./sx1301/README.md) - Semtech SX1301 multi-channel LoRaWAN baseband concentrator SPI driver and regional channel tables.
