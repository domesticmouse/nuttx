# IEEE 802.11 Wireless LAN Drivers (`drivers/wireless/ieee80211`)

## Overview
Groups IEEE 802.11 Wi-Fi and IEEE 802.11ah Wi-Fi HaLow FullMAC network drivers for Broadcom/Cypress BCM43xxx and Morse Micro chipsets.

## Subdirectories & Boundaries
- `bcm43xxx`: [./bcm43xxx/README.md](./bcm43xxx/README.md) - Broadcom/Cypress BCM43xxx and CYW43439 SDIO/gSPI FullMAC IEEE 802.11 Wi-Fi driver.
- `morse`: [./morse/README.md](./morse/README.md) - Morse Micro IEEE 802.11ah (Wi-Fi HaLow) SPI network driver, HAL, and OSAL.
