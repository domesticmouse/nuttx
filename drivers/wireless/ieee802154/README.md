# IEEE 802.15.4 Transceiver Drivers (`drivers/wireless/ieee802154`)

## Overview
Groups IEEE 802.15.4 WPAN transceiver and radio-MAC drivers for Atmel AT86RF23x, Microchip MRF24J40, and Digi XBee devices.

## Subdirectories & Boundaries
- `at86rf23x`: [./at86rf23x/README.md](./at86rf23x/README.md) - Atmel AT86RF231/AT86RF233 2.4 GHz IEEE 802.15.4 SPI transceiver lower-half radio driver.
- `mrf24j40`: [./mrf24j40/README.md](./mrf24j40/README.md) - Microchip MRF24J40 2.4 GHz IEEE 802.15.4 SPI transceiver lower-half radio driver.
- `xbee`: [./xbee/README.md](./xbee/README.md) - Digi XBee IEEE 802.15.4 SPI driver, MAC layer, and 6LoWPAN network device wrapper.
