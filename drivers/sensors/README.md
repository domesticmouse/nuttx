# Sensor Subsystem and Device Drivers (`drivers/sensors`)

## Overview
Implements the NuttX upper-half sensor framework (supporting both the uORB-style topic/circular-buffer model in `sensor.c` and legacy character-device sensor drivers), cross-core RPMSG sensor proxying (`sensor_rpmsg.c`), userspace virtual sensor registration (`usensor.c`), procfs sensor monitoring (`sensor_monitor.c`), GNSS upper-half parsing (`gnss_uorb.c`), quadrature encoder (`qencoder.c`), Hall effect (`hall3ph.c`), zero-cross (`zerocross.c`), and hardware lower-half drivers for accelerometers, gyroscopes, IMUs, magnetometers, barometers, temperature/humidity, ambient light, gas/air-quality, current/power, ultrasonic, and optical sensors over I2C, SPI, 1-Wire, and UART.

- `[sensor_monitor.c:sensor_monitor_initialize]`, `[sensor_monitor.c:sensor_monitor_level]` - Procfs-based sensor logging level monitor.
- `[usensor.c:usensor_initialize]` - Registers `/dev/usensor` allowing userspace applications to dynamically create and unregister virtual uORB sensors.
- `[gnss_uorb.c:gnss_register]`, `[gnss_uorb.c:gnss_unregister]` - GNSS upper-half driver that parses NMEA sentences (via minmea) and publishes uORB GNSS topics alongside `/dev/ttyGPS*` device nodes.

## Invariants
- `[sensor.c:sensor_custom_register]` requires a non-null `lower` half pointer (`DEBUGASSERT(lower != NULL)`) and valid event buffer size (`esize > 0`).
- `[sensor.c:sensor_remap_vector_raw16]` requires the coordinate placement index `place` to be within the bounds of `g_remap_tbl` (`DEBUGASSERT(place < (nitems(g_remap_tbl)))`).
- Upper-half wrappers (`[qencoder.c:qe_register]`, `[hall3ph.c:hall3_register]`, `[zerocross.c:zc_register]`) assert that `lower->ops->setup` and `lower->ops->shutdown` (or `lower->zc_enable`) are non-null before registering character devices.
- Lower-half bus drivers assert valid bus handles (`DEBUGASSERT(i2c != NULL)`, `DEBUGASSERT(spi != NULL)`, `DEBUGASSERT(uartpath != NULL)`) and valid device I2C addresses (e.g., `[ltc4151.c:ltc4151_register]`, `[mb7040.c:mb7040_register]`, `[mcp9600_uorb.c:mcp9600_register]`, `[sht4x_uorb.c:sht4x_register]`, `[nau7802.c:nau7802_register]`).

## Side Effects
- Registers VFS device nodes under `/dev/uorb/*`, `/dev/sensor/*`, `/dev/usensor`, or custom paths via `register_driver`.
- Performs I2C (`I2C_TRANSFER`), SPI (`SPI_SNDBLOCK`, `SPI_EXCHANGE`), 1-Wire, GPIO interrupt attachment, and UART I/O transactions to configure sensor registers and sample data.
- Spawns polling kernel threads or schedules work-queue jobs (`work_queue`) and synchronizes concurrent access to circular buffers and device state via `nxmutex_lock`, `nxsem_wait`, and critical sections.
- `[sensor_rpmsg.c:sensor_rpmsg_initialize]` creates RPMSG endpoints (`rpmsg_create_ept`) and broadcasts sensor advertisements, subscriptions, and sample payloads across processor cores.
